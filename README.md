# Mi proyecto TIC II

## Descripción
Página web que presenta tres grados universitarios de la Universidade da Coruña (UDC) relacionados con el diseño y la construcción.
Permite conocer qué se estudia en cada grado, comparar sus características y consultar sus salidas profesionales.

## Tecnologías
- HTML
- CSS
- Bootstrap
- Git y GitHub

## Estructura del proyecto:
index.html: página principal
opciones.html: comparación de los grados
salidas.html: salidas profesionales
css/: hojas de estilo
img/: imágenes utilizadas en la web
