# Proyecto TIC II

## 1. Objetivo

Creación de una página web sobre tres grados universitarios de la Universidade da Coruña (UDC)
La web permite conocer qué se estudia en cada grado, comparar sus características y consultar sus salidas profesionales.

## 2. Páginas del proyecto

- index.html
- opciones.html
- salidas.html

## 3. Tecnologías utilizadas

- HTML
- CSS
- Bootstrap
- Git y GitHub
