TIC 2 – Práctica 1
DESCRIPCIÓN:
Página web que presenta tres grados universitarios de la Universidade da Coruña (UDC) relacionados con el diseño y la construcción.
Permite conocer qué se estudia en cada grado, comparar sus características y consultar sus salidas profesionales.
Contenido de la web
La página está dividida en tres apartados:
Inicio: presentación de los tres grados universitarios.
Opciones: comparación de los grados de Arquitectura, Arquitectura Técnica e Ingeniería en Diseño Industrial y Desarrollo del Producto.
Salidas: información sobre las salidas profesionales de cada grado.
HERRAMIENTAS UTILIZADAS:
HTML
CSS
Bootstrap
ESTRUCTURA DEL PROYECTO:
index.html: página principal
opciones.html: comparación de los grados
salidas.html: salidas profesionales
css/: hojas de estilo
img/: imágenes utilizadas en la web
